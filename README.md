# Medicine Store Admin Dashboard

## About the Project

**Medicine Store Admin** is an administrative dashboard for managing a medical
store. The application allows the administrator to manage orders, products,
suppliers, and customers.

Backend:
[Swagger documentation with routes](https://e-pharmacy-backend-0kth.onrender.com/api-docs/)

## Features

### Authentication

- Login with email and password
- Form validation using Yup
- Session persistence via JWT token

### Dashboard

- Statistics: total products, suppliers, customers
- List of recent customers
- Income/Expenses table

### Orders

- View all orders
- Filter orders by user name
- Pagination (5 orders per page)
- Different colors for order statuses

### Products

- View all products
- Add new product
- Edit product
- Delete product
- Filter by product name
- Pagination

### Suppliers

- View all suppliers
- Add new supplier with date picker
- Edit supplier
- Filter by supplier name
- Pagination
- Supplier status (Active/Deactive)

### Customers

- View all customers
- Filter by customer name
- Pagination

## Функционал

### Авторизация

- Вход в систему по email и паролю
- Валидация формы с помощью Yup
- Сохранение сессии через токен JWT

### Dashboard (Главная страница)

- Статистика: количество продуктов, поставщиков, клиентов
- Список последних клиентов
- Таблица доходов и расходов

### Orders (Заказы)

- Просмотр всех заказов
- Фильтрация заказов по имени пользователя
- Пагинация (по 5 заказов на странице)
- Разные цвета для статусов заказов

### Products (Продукты)

- Просмотр всех продуктов
- Добавление нового продукта
- Редактирование продукта
- Удаление продукта
- Фильтрация по названию
- Пагинация

### Suppliers (Поставщики)

- Просмотр всех поставщиков
- Добавление нового поставщика с выбором даты
- Редактирование поставщика
- Фильтрация по имени
- Пагинация
- Статус поставщика (Active/Deactive)

### Customers (Клиенты)

- Просмотр всех клиентов
- Фильтрация по имени
- Пагинация
